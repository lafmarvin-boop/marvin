# Pixel Realm

Jeu d'action-RPG en pixel art. Un seul fichier : ouvre `index.html` dans un navigateur.

- Création du héros : nom, race (Humain, Elfe, Nain, Orc), peau, coiffure, cheveux, armure, arme, 2 compétences.
- Monde en étapes : Forêt, Marais, Château. Boss toutes les 3 étapes.
- Butin : or, potions, coffres de boss (arme/armure +1, compétences rares).
- Camp : boutique (armes, armures, cape, casque, 3e emplacement, compétences).
- Sauvegarde automatique (localStorage).

Touches : ← → / A D bouger · Espace / W sauter · K / J attaquer · 1 2 3 compétences · Q potion.
Mobile : boutons tactiles sous l'écran.
